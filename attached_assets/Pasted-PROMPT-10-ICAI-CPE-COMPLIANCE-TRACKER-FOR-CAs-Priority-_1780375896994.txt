PROMPT 10 — ICAI & CPE COMPLIANCE TRACKER FOR CAs
Priority: SMART ADDITION — No competitor has this, creates daily habit
Context
Every Indian CA must complete 120 CPE (Continuing Professional Education) hours
in a 3-year block to maintain their ICAI membership. Add this personal professional
tracker inside GSTify to create a deeply personal daily use reason.

10.1 — New Database Tables
ca_professional_profiles

id (uuid, PK)
user_id (uuid, FK → ca_users)
tenant_id (uuid, FK)
membership_number (text) — ICAI membership number (e.g. "123456")
membership_type (enum) — ASSOCIATE | FELLOW
cop_number (text) — Certificate of Practice number, nullable
cop_expiry_date (date) — nullable
current_cpe_block_start (date) — start of current 3-year block
current_cpe_block_end (date) — end of current 3-year block
cpe_hours_required (integer) — default 120
cpe_hours_structured_required (integer) — default 90 (must be structured)
cpe_hours_unstructured_max (integer) — default 30
created_at (timestamp)

cpe_activities

id (uuid, PK)
user_id (uuid, FK)
tenant_id (uuid, FK)
activity_date (date)
activity_type (enum) — SEMINAR | WEBINAR | CONFERENCE | SELF_READING | WRITING |
TEACHING | ICAI_PROGRAM | E_LEARNING | STUDY_CIRCLE
activity_category (enum) — STRUCTURED | UNSTRUCTURED
title (text) — name of the seminar/webinar/article
organizer (text) — ICAI / WIRC / ICAI branch name / External organizer
hours_claimed (decimal) — hours to count toward CPE
certificate_url (text) — uploaded certificate, nullable
icai_activity_id (text) — nullable (ICAI's own activity ID if registered on ICAI portal)
verification_status (enum) — SELF_REPORTED | VERIFIED | REJECTED
notes (text)
created_at (timestamp)

icai_upcoming_events (maintained by GSTify team)

id (uuid, PK)
title (text)
organizer (text)
event_type (enum) — SEMINAR | WEBINAR | CONFERENCE | STUDY_CIRCLE
event_date (date)
event_time (time)
duration_hours (decimal)
registration_url (text)
is_free (boolean)
fee_amount (decimal) — nullable
cpe_hours_awarded (decimal)
topics (text array)
region (text) — "National" / "Western" / "Southern" / "Eastern" / "Northern"
created_at (timestamp)

10.3 — Design Guidelines

Progress ring: most important visual element — make it large, clear, satisfying to look at
Green when on track, orange when slightly behind, red when at risk
"On track" message: positive, encouraging — not scary
Activity log: quick to fill in (max 30 seconds per activity)
Certificate upload: optional but encouraged — "Certificates help if ICAI asks for records"
Upcoming events: show only future events, remove past ones automatically
